# Security policy

This repository is primarily a mathematical research and computational evidence record.

## Reporting

Please do not publish credentials, access tokens, private data, or other sensitive
information in issues or commits. For a suspected security vulnerability in
repository code or automation, use GitHub's private vulnerability-reporting
mechanism for this repository if it is enabled. If private reporting is not
available, contact the repository maintainers through the RFT-SIRM GitHub
organization profile and avoid including exploitable details in a public issue.

## Scope

Reports about mathematical disagreements, numerical discrepancies, or failed
research hypotheses are welcome as ordinary issues when they contain a
reproducible example and no sensitive information. A passing CI workflow should
not be interpreted as a security audit or as proof of a mathematical claim.
